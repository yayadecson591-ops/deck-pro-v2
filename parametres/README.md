# Paramètres Deck Pro

Les réglages techniques sont regroupés ici et ne font pas partie de l'utilisation quotidienne.

- Les secrets et clés restent côté infrastructure.
- Aucun réglage technique n'est demandé à l'utilisateur.
- Les données sportives et cotes doivent rester issues de sources live réelles.
- Les paris réels automatiques restent désactivés.
